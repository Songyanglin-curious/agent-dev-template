# 对 DSH 开发体系的研究

本目录保存对 DeepSeek Harness（DSH）研发体系的研究结论：它如何组织研发活动、文档与知识为什么按现在的职责分层，以及哪些做法可以脱离它的技术栈复用。

## 范围

研究基线是 DSH 上游仓库 `master` 上的发布 `dsh-v0.2.3-alpha.2`（2026-11-22）。原始调查完成于 2026-11-26，整理这些文档时按同一基线复核了案例和规则，此后未再复核。DSH 仍在演进，引用具体路径、规则或案例前，先回到上游仓库确认。

本目录拥有“对参考体系的研究结论”：可复用的设计原则、支持它的证据，以及不采纳某些做法的理由。它不拥有本仓库的当前机制（→ [体系架构](../architecture.md)、[文档标准](../AGENTS.md)）和已经确定的决策（→ [Agent Note](../../.agents/notes/README.md)）。DSH 的做法在这里是参考，不是本仓库的规则；采纳其中任何一条，都要落到准则、防御模式、cookbook、Skill 或 Agent Note。

## 材料处置

形成这两篇文档的原始梳理材料已清理：逐页笔记、画布截图、全量 Skills 与 Scripts 清单、术语对照表、过期流程草稿和仓库自评。重复内容并入这些文档，需要原文时以 DSH 仓库和 Git 历史为准；DSH 原始仓库不属于本仓库，也不由本目录维护。
