# cookbook

本目录保存已经研究清楚、以后会重复执行的固定操作步骤。它回答“这件事具体怎么做”，假设读者已经知道为什么要做。

## 与相邻层级的分界

- **Skill**：面对需要判断的场景，规定加载哪些知识、按什么顺序决策，例如 [doc-writing](../../.agents/skills/doc-writing/SKILL.md)。
- **cookbook**：步骤确定、结果可验证、不需要临场设计，例如新增一条门禁或初始化模板。
- **core-guidelines / defensive-patterns**：规则与缺陷检查，不描述操作序列。

## 编写标准

每个指南包含五节：`适用场景`、`前置条件`、`步骤`、`验证`、`失败恢复`。步骤用编号列表，每条是一个可执行动作；命令按文档展示的样子实际执行过；验证写明可观察结果，不写“应该可以”。步骤依赖的脚本、清单和文档使用相对链接。

## 维护

操作步骤因脚本、清单或目录变化而失效时，在同一次变更中更新对应指南。指南引用的命令或文件消失时，链接检查会失败；命令语义变化但路径不变时，必须由作者同步。
