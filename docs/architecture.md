# 研发文档体系架构

本文介绍 agent-dev-template 的研发文档体系，包括整体组成、内容职责、相互关系以及维护方式。

## 一、设计目标

让每个页面都可被搜索、可被新人读懂，并且对 agent 和维护者足够精确；同时让文档网站始终是仓库 Markdown 经过测试的投影

核心原则：**每类信息有明确的归属位置，文档之间通过引用建立联系，而不是重复保存相同内容。**

## 二、整体组成

由以下模块划分：

1. [外部输入](../研发输入)  

2. [输入进行标准化](../.agents/notes)  对于输入

3. [研发与文档同步变化](../docs)

4. [变化归档](../persistence-changes)
