# Agent Note: 文档模板章节中文化

Status: implemented

## Problem

doc-writing 模板的固定章节名长期使用 `Summary`、`Table of Contents`、`Declaration` 等英文，而正文和仓库其他文档使用中文。读者需要在两种术语之间切换，模板、Skill 政策、门禁常量和现有模块文档也各自维护一份英文标题。把标题改为中文会同时影响 TOC 锚点、模块门禁、持久化记录门禁和测试，不能只改模板。

## Decision

固定章节名统一为：`摘要`、`目录`、`延伸阅读`、`开发备注`、`机器声明`、`兼容性`、`验证`；模板教学标题 `Frontmatter` 改为 `元数据`，持久化变更的 H1 改为 `持久化变更：<具体变更>`。

迁移范围包括：

- 5 个 doc-writing 模板及其目录锚点；
- doc-writing 的 SKILL、结构政策、评审和风格参考；
- `verify-module-readmes` 与 `verify-persistence-records` 的标题常量和诊断；
- 现有 `scripts/README.md` 模块文档；
- 相关文档中的术语和锚点；
- `gates.test.ts` 中模块摘要和三类持久化记录的中文标题正负测试。

不改变 YAML 字段、`kind`、机器声明块、digest 格式、Agent Note 和 Postmortem 骨架；`Frontmatter` 只是模板说明标题，不改变元数据格式。

## Alternatives considered

**继续保留英文固定标题。** 跨页面检索可以依赖固定英文名，但正文、模板和读者术语长期分叉；这次选择以中文为唯一标题语言。

**只改模板，不改门禁。** 模板生成的中文文档会被仍查找 `Summary`/`Declaration` 的门禁拒绝，不能形成可运行体系。

**连 Agent Note 和 Postmortem 一起改。** 这两类文档有独立骨架和生命周期，不属于 doc-writing 模板；混入本次迁移会改变无关协议。

**在脚本中继续硬编码标题，不做测试。** 模板和门禁会再次漂移；本次用中文正向和英文负向用例锁定对应关系。

## Consequences

文档标题和正文使用同一语言，TOC 锚点需要同步迁移；模块和持久化记录的现有文档必须一次完成。标题仍同时存在于模板、Skill 文档和两个门禁脚本中，后续改标题需要同时更新这些位置，测试会暴露遗漏。Agent Notes、Postmortem 和机器声明字段保持原样。

## Verification

- `pnpm run test:gates` 覆盖模块摘要和三类持久化记录的中文标题正向、英文标题负向。
- `pnpm run test:docs` 校验模板、Skill、`scripts/README.md` 的链接与锚点。
- `pnpm run test:notes` 校验本记录格式和生命周期。
- `pnpm run test:tools` 覆盖变更范围工具，确认迁移未影响工具行为。
