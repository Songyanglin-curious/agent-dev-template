# 整体

agent-dev-template/      # Agent 研发模板项目
├── AGENTS.md            # 项目级研发规则与导航入口
├── README.md            # 项目介绍与使用说明
├── docs/                # 系统认知、工程规范与知识文档
│   ├── AGENTS.md        # 文档维护规则
│   ├── 架构.md          # 对应architecture.md
│   ├── 子系统/          # 对应subsystems 这个需要考虑
│   ├── 故障复盘/        # 对应postmortem  记录 隐蔽性 系统性 重复发现成本高
│   ├── 防御性模式/      # 对应 defensive patterns 识别和防止错误但是不用通读故障复盘
│   ├── 核心开发准则/    # 对应 core guidelines 后续改按照怎样的原则设计和编辑代码
│   └── 工程操作指南/    # 对应cookbook 把以前已经研究清楚的操作方法保存下来，避免每一个新 Agent 都重新调查如何完成相同的任务。
├── .agents/             # Agent 研发流程、设计提案与决策记录
│   ├── notes/           # 将研发输入转化为标准化工程变更，并对工程变更进行生命周期管理的一套机制。
│   └── skills/          # 积累下来的知识真正参与研发
├── scripts/             # 工程检查与自动化脚本
└── 研发输入/            # 原始需求、外部约束与研发参考资料
