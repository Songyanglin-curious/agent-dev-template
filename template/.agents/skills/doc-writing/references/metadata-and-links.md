# 元数据与链接

## 让读者选对页面

声明 `kind` 的文档使用 YAML frontmatter。`description` 写一到两句：说明页面负责哪种能力、在什么情形下值得打开，使用能与相邻页面区分的术语。不要重复标题、留下填写说明或使用宣传语。标题、路径和源码已经说明的名称、受众和标签不要在元数据中再建一套。

`kind` 按文档职责选择，而非目录深度：模块介绍一个可维护单元；模块组只做分工和导航。持久化变更、发布和格式是记录，不使用 README 文件名。具体字段、位置和章节见 [kind 与模板](../SKILL.md#文档类型与模板)。任务与 Agent Note 使用自己的格式，不套用这组 frontmatter。

## 让链接经得起移动

从当前文件写指向真实归属方的相对链接；不要用站点根路径充当仓库根，也不要写本机绝对路径。外部资料保留完整 URL。将尚未创建的路径写入模板占位说明，不制造可点击的假目标。

同一页的目录链接到标题锚点。相对链接带章节时同时核对目标文件和标题；必须跨改名保持稳定的章节可显式声明锚点。移动页面或重命名标题时，同次修复索引、正文、生成导航和其他入站引用。生成区域由生产方更新。
