# 检索原则

检索只能定位候选，不能替代逐段阅读。先在指定范围内通读至少一处密集文字，再围绕工程中实际使用的语言寻找草稿标签、评审轮次、分支口吻、模糊延期和控制流复述。

- 限定真实搜索根，明确包含需要审计的隐藏文件，最后应用排除规则；不沿符号链接进入依赖目录或其他项目。
- 在本次范围内选一个应命中的短语，再选一个相似但有明确技术含义的反例。调整完整词界、语言和大小写；不能用来源项目的示例代替校准。
- 逐个返回上下文，核对引用能否解析、时间是否描述运行时对象、理由是否用于防止误用。无法定性的候选留作待核验，不批量替换。
- 修改后用同样范围复查，同时重读未命中但风险高的段落。保留命中并说明原因，比把全部搜索结果删到零更可靠。
