# 通用准则

<a id="g1-规则格式"></a>
## G.1 规则格式

**要求**：每条准则具有稳定编号和四个字段。`要求` 用祈使句写必须做到的事；`理由` 写违反后的具体代价；`判据` 写评审者如何识别违规；`边界` 写适用范围的例外和不适用的场景。

**理由**：没有判据的规则只能靠印象执行，评审者无法给出可复核的意见；没有边界的规则会在不适用的场景被机械套用，最终被整体忽略。

**判据**：规则缺少任一字段，或 `判据` 只是复述 `要求`；编号在删除后被重新分配；同一条规则在多个文件中重复定义。

**边界**：只适用于 `docs/core-guidelines/` 下的规则。模块文档中的契约、防御性模式和 cookbook 步骤有各自的格式，不套用本结构。
