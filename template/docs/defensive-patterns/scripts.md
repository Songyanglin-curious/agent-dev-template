# 脚本与门禁

<a id="dp-s1-语料静默缩小"></a>
## DP-S1 语料静默缩小

- **要求**：改文件匹配、排除规则或目录后，核对检查的数量和应纳入的文件。
- **缺陷**：范围意外缩小，结构违规未被检查，结果却显示成功。
- **判据**：新增同类文件不影响计数；应覆盖的目录被整体排除；未说明检查了多少文件。
- **边界**：项目确实没有该类文档时，数量为零可以通过，但应能从摘要识别。
- **正确**：用一个应纳入的输入和一个应排除的输入验证发现范围，而不只检查退出码。
- **错误**：目录移动后只看到通过便认为全部文件均已检查。

<a id="dp-s2-诊断不可定位"></a>
## DP-S2 诊断不可定位

- **要求**：失败诊断逐项写明目标路径、可得的行号与期望值。
- **缺陷**：修复者只能重跑或阅读脚本，无法直接定位出错工件。
- **判据**：多个违规合成一个总数，或只报出共享解析器而非出错的输入。
- **边界**：清单级错误可报告清单路径与条目键，不必伪造行号。
- **正确**：无效豁免报出清单、条目与移除或修正它的条件。
- **错误**：发现坏链接却只打印“检查失败”。

<a id="dp-s3-门禁行为与文档不一致"></a>
## DP-S3 门禁行为与文档不一致

- **要求**：改变扫描范围、检查项、清单格式或退出语义时，同批更新[文档门禁](../subsystems/documentation-gates.md)和受影响的操作指南。
- **缺陷**：读者误以为未检查的文件已获验证，或按错误的前置条件执行命令。
- **判据**：命令清单与文档描述的总入口不同，或规则缺失时实际结果与说明相反。
- **边界**：共享函数重构但可观察行为未变时，不需要为重述实现而改文档。
- **正确**：对修改后的条件运行一个反例，核对诊断，再更新检查范围说明。
- **错误**：把新检查写入使用指南，却没有注册入口或可复现的执行路径。
